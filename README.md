# Student Grades Management System 🎓📊

## 📝 Description
A console-based C++ application designed to manage, process, and evaluate student grades. This project demonstrates the practical use of data structures (like arrays or vectors), loops, and algorithms to perform statistical calculations on a set of data.

## ✨ Features
- Data Entry: Input and store grades for multiple students.
- Grade Calculation: Calculate the total and average grades of the class.
- Performance Tracking: Identify the highest and lowest grades among the students.
- Detailed Report: Display a formatted summary of all students and their respective scores.

## 🛠️ Technologies Used
- Language: C++
- Environment: Console / Terminal
